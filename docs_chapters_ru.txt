Глава 1. Linux — пункты 1.1–1.4

Глава 4. Docker/PostgreSQL — пункты 3.1–3.4
Многоэтапная сборка JDK -> JRE, непривилегированный runtime, персональный тег.
Compose: приложение + PostgreSQL, db как hostname, закрытый порт БД,
именованный том, отдельная сеть, pg_isready и проверка готовности приложения.
Управление контейнерами, изменение версии и пересборка, сохранность записи
после down/up без -v, полный CRUD через HTTP с настоящей базой.

SCM job и пять стадий: Checkout, Build, Test, Docker Build, Verify.

исправление и успешный повтор. Poll SCM и доказательство автоматического
запуска по новому коммиту. Различить CI, Continuous Delivery и Deployment.
